# Liang Jin Academic Homepage

A responsive bilingual academic homepage for Liang Jin, College of Electronic Science, National University of Defense Technology.

## Preview locally

Open `index.html` directly in a browser, or run a small local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `L-Jin-bupt.github.io`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages** in the repository.
4. Select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Visit `https://L-Jin-bupt.github.io/` after deployment finishes.

## Personalize

- Replace the initials card in `index.html` with a portrait when available.
- Update the short biography with academic positions and education history.
- Add new papers to the publication list and new repositories to the code section.
- If the GitHub username changes, update the GitHub links and repository name above.
